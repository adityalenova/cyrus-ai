About us

A directory run like a library, not an ad network

cyrus.ai catalogs the skills, rules, configs and servers that power AI coding agents — and is honest about where every number comes from.

The problem we got tired of

Choosing agent tooling in 2026 meant ten browser tabs of GitHub search, listicles stuffed with paid placements, and READMEs that promised senior-engineer quality. Meanwhile the signal developers actually trust — stars, contributors, license, last push — sat scattered and unsearchable.

So we built the index we wanted: 528 real repositories across five shelves, every one a live GitHub project, ranked by the only vote that can't be bought. No sponsored slots. No algorithmic boosting. When we feature something, it's because it's at the top of a shelf.

What we believe

  • Ranking must be falsifiable. Every number traces to the GitHub API with a timestamp.
  • Maintainers deserve the money. The sponsor board isn't a feature for us — it's the point. Skills are infrastructure, and infrastructure has upkeep costs.
  • Depth beats breadth. A repo page with contributors, languages and pulse is worth ten cards with a one-line blurb.
  • Stay honest about the demo. Sign-in and the forum are local-first prototypes; we say so on the page that offers them.

Data & methodology

The snapshot regenerates from 13 GitHub topic-search queries (agent-skills, claude-skills, claude-code, cursorrules, mcp-server, agents-md and friends), pulled with an authenticated GitHub API client on 2026-10-02. Results are deduplicated by repo name, classified into shelves by topics and description with a hand-curated override for well-known projects, filtered (≥25 stars, description required), and capped per shelf. Cards show snapshot figures; repo pages re-fetch /repos, /contributors and /languages live and label the source.

Known limits, stated plainly: stars undercount private/teamed usage; newly archived repos keep their stars until the next refresh; and classification of a repo that mixes MCP with skills is a judgment call we make per-project, not per-keyword. The generation script ships with the site — audit it.

Who builds this

cyrus.ai is built by a solo developer in Hyderabad — an AI-native product in the truest sense: designed, written and shipped with the same agent tooling it catalogs. The stack is deliberately boring: HTML, CSS, vanilla JS, the GitHub API, and a regeneration script.
